## Introduction  

This project is divided into four distinct tasks, each focusing on a key aspect of logical reasoning, circuit simplification, or cryptography.  
The deliverables for each task include a C++ implementation and relevant analytical work.  

---

## Tasks Overview  

### Task 1: Valid and Invalid Argument  

#### Objective  
Analyze a logical argument with premises and a conclusion to determine its validity and satisfiability.  

#### Implementation Details  
- Compute the truth table for premises and the conclusion.  
- Determine whether the argument is:  
  - **Satisfiable** or **Not Satisfiable**.  
  - **Valid** or **Falsifiable**.  

#### Output  
A detailed message indicating:  
1. The satisfiability of the set of formulas.  
2. The validity of the argument.  

---

### Task 2: Digital Logic Circuit Simplification  

#### Objective  
Simplify a given digital logic circuit and verify the equivalence of the simplified expression with the original.  

#### Implementation Details  
- Generate the truth table for the original and simplified logical expressions.  
- Check for equivalence between the two expressions.  
- Identify input values that satisfy the circuit.  
- If unsatisfiable, modify one gate and reanalyze.  

#### Output  
1. Verification of equivalence between the original and simplified circuits.  
2. Satisfiability analysis of the circuit.  

---

### Task 3: Ciphering  

#### Objective  
Encrypt a message using the Affine Cipher technique.  

#### Implementation Details  
- Input: Message to be ciphered and ciphering keys.  
- Apply the Affine Cipher formula to encode the message.  

#### Output  
The ciphered message generated using the Affine Cipher.  

---

### Task 4: Deciphering  

#### Objective  
Decrypt a message encoded with the Affine Cipher.  

#### Implementation Details  
- Derive deciphering keys from the provided ciphering keys.  
- Input: Ciphered message and deciphering keys.  
- Decode the message using the derived keys.  

#### Output  
The original message decoded from the Affine Cipher.
